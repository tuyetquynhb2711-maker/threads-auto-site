threads-auto

Personal content workflow tool

threads-auto is a private tool used by a single content creator to organise short-video production. It runs on the creator's own computer and uses Google APIs only to:

  • create and update one Google Sheet that the tool itself created, used as a work log;
  • upload video and image files that the tool itself rendered to a Google Drive folder the tool created.

The tool is not offered to the public and does not collect data from other users.
